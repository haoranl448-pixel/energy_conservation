# 01_data_processing 代码说明

本目录保留数据清洗链路中的早期脚本和专项工具。当前端到端任务优先使用 `00_main_pipeline/01_data_process.py`，这里的文件主要用于追溯原始处理步骤或单独修复数据。

| 文件 | 具体作用 | 状态 |
| --- | --- | --- |
| `step_1.py` | 第一阶段原始 Excel 整理与字段预处理，为后续分段生成中间数据。 | 历史流程 |
| `step2.py` | 将第一阶段数据按运行连续性切分为 `segment`，计算轨迹与能耗字段并形成 Step2 结果。 | 历史流程/数据追溯 |
| `process_target_v2.py` | 面向新版目标数据执行字段清洗、时间处理和目标区间输出。 | 数据专项工具 |
| `process_line5.py` | 针对5号线原始文件结构执行批量清洗和区间整理。 | 历史专项 |
| `conbine.py` | 合并多个原始或中间数据文件；文件名中的 `conbine` 为早期拼写，实际含义为 combine。 | 历史工具 |
| `conbine_ato.py` | 合并 ATO 相关数据或曲线结果，供后续模板/仿真使用。 | 历史工具 |
| `segment_chooose.py` | 从处理结果中筛选指定区间或趟次；`chooose` 为保留的旧文件名。 | 辅助工具 |
| `segment_class.py` | 根据运行时间等信息生成区间运行等级分类结果。 | 历史工具 |
| `add_class.py` | 给已处理轨迹补写运行等级标签。 | 辅助修复工具 |
| `get_load.py` | 从历史静态记录中提取并整理车重/载重信息。 | 辅助工具 |

注意：这些脚本存在较多固定路径和旧字段口径。新数据优先通过主流程处理；单独运行前应先确认输入目录和列名。
