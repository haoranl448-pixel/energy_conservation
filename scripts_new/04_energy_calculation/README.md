# 04_energy_calculation 代码说明

本目录保存物理能耗和模型修正能耗的早期计算脚本。当前候选曲线能耗菜单由 `00_main_pipeline/06_ato_generated_results_energy.py` 统一生成。

| 文件 | 具体作用 | 状态 |
| --- | --- | --- |
| `energy.py` | 早期通用能耗计算入口。 | 历史版本 |
| `calculate_e.py` | 对单条或单区间轨迹计算基础能耗。 | 历史工具 |
| `calculate_e copy.py` | `calculate_e.py` 的试验副本，文件名含空格，不建议调用。 | 备份 |
| `calculate_e_new.py` | 在基础版本上调整输入字段或能耗计算逻辑。 | 实验版本 |
| `energy_all_line.py` | 汇总多个区间的能耗，形成全线结果。 | 历史工具 |
| `et_vt_04_06.py` | 分析能耗-时间及速度-时间关系的专项脚本。 | 实验分析 |

能耗口径可能包含“实测电能”“轮周牵引机械能”和“残差修正预测能耗”三类，使用这些旧脚本时必须查看其输入列及单位，不能直接横向合并。
