# OpenTrack Model Archive

- `editSpeed.opentrack`: latest working OpenTrack line model used for speed-limit experiments.
- `1111111.opentrack`: earlier full-line model snapshot.
- `test123.opentrack`, `testApiFirst5.opentrack`, `picture.opentrack`: earlier test models retained for traceability.
- `STA_1-STA_27.otsimcor`: simulation comparison/configuration file for stations 1 through 27.
- `History_Trips_Import.xml`, `export-timetable.xml`, `export-course.courses`, `export-cou.xml`: supporting timetable and course import/export artifacts.

OpenTrack application binaries are intentionally not included; this directory contains project-owned model inputs only.
