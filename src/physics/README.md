# physics 代码说明

| 文件 | 具体作用 | 状态 |
| --- | --- | --- |
| `static_model.py` | 从线路基础 Excel 中读取相邻站区间、里程、坡度和曲率等静态信息。 | 公共线路模块 |
| `train_simu.py` | 当前新版列车理论能耗模型；保持全线绝对里程坐标，计算轮周侧正牵引机械能，不含牵引效率、辅助电耗和再生制动回收。 | 当前物理模型 |
| `train_simu_v1_backup_20260828.py` | 修改全线坐标逻辑前保存的 v1 版本，用于结果追溯和新旧口径复核。 | 冻结备份 |
| `train_sim.py` | 早期按照 Simulink 模块结构直接转写的理论机械功模型，包含绘图和较多验证逻辑。 | 历史参考实现 |

当前规划复算和25趟对比应使用 `train_simu.py`。对外表述统一为“Simulink 仿真机械能耗”。
